Method

∇·(ε ∇φ) = 0 on the cross-section strip φ = 1 V, ground and far box φ = 0 half domain, symmetry wall at x = 0 graded grid, finest cell 0.004·min(w/2, h) at the edge finite-volume 5-point stencil, interface on a grid line conjugate gradients + IC(0) preconditioner C = 2 Σ g (Δφ)² · ε0 (field energy) C0 = same with εr = 1 εeff = C / C0, Z0 = 1 / (c √(C · C0))

Quasi-static (TEM) model: valid while the substrate is thin compared with the wavelength. The closed forms are Hammerstad–Jensen 1980 (static Z0 and εeff, with their thickness correction) and Kirschning–Jansen 1982 (εeff dispersion, fitted for t = 0, valid to f·h = 25 GHz·mm, 0.1 ≤ w/h ≤ 100, εr ≤ 20; the shaded part of the plot is outside that range). With t > 0 the thickness-corrected static εeff is used as its starting point.
