Coaxial line

The field lives between two conductors. Its shape sets the impedance, the loss, the power limit and the first higher mode.

Method

Z0 = (η0 / 2π√εr) · ln(b/a) a = d/2, b = D/2 Rs = √(ωµ0 / 2σ) αc = Rs (1/a + 1/b) / (4π Z0) [Np/m] αd = (π f √εr / c) · tan δ [Np/m] E(r) = V / (r ln(b/a)), max at r = a Pmax = (Ebd · a · ln(b/a))² / (2 Z0) (peak, matched) TE11: J1′(x) Y1′(cx) − J1′(cx) Y1′(x) = 0, x = kc·a, c = b/a (smallest root) approx. kc ≈ 2/(a+b)

Conductor loss uses a smooth surface (no roughness) and the same metal for both conductors. Power is the peak-field limit only, not the thermal (average-power) limit. The default breakdown field, 3 kV/mm, is air at sea level; for filled cables treat it as a conservative air-gap figure.
